# Приглашение для Катюши

Откройте index.html в браузере. Для публикации загрузите index.html, style.css, app.js, .nojekyll и папку assets в корень статического сайта, например GitHub Pages.

Сценарий: приглашение → согласие → дата → время по Москве → занятие → подтверждение → финальная карточка. На финальном экране кнопка «Отправь мне ответ» открывает выбор Telegram или ВКонтакте. Автоматической отправки и серверного сохранения нет. При обновлении страницы выбор сбрасывается.

Стикеры Peach Goma Cats @PeachLovesGoma: https://t.me/addstickers/peachgomapack
Оригинальные файлы стикеров сохранены локально, без перерисовки.
Источник: https://tgstickers.online/stickers/8221
Авторские права на персонажей и стикеры принадлежат их авторам.

Оформление адаптировано под телефон. Внешние шрифты Comfortaa и Nunito загружаются через Google Fonts; без интернета используются системные шрифты. Сам сайт и стикеры работают локально.

Дата встречи: с 16 октября 2026 года, прошедшие дни недоступны. Будни: 18:00 и 20:00. Выходные: 12:00, 14:00, 16:00, 18:00, 19:00, 20:00. Ручного ввода времени нет.
Стикеры анимированы средствами CSS: покачивание, подпрыгивание, наклон и сердечки. Внутри исходных WEBP персонажи статичны. При системной настройке уменьшения движения анимация отключается.

Telegram: готовый текст с датой, временем и занятием плюс ссылка. ВК: ссылка с выбором в параметрах и заголовок ответа; при открытии ссылки отображается выбранная карточка. Пользователь выбирает получателя и отправляет самостоятельно. Есть копирование текста с ручным запасным вариантом. Из локального файла доступно только копирование; ссылки работают после публикации по HTTPS.
